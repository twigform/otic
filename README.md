This is a project for school, but hopefully it'll also be an actually usable application by the end!

# TIMELINE:

Week 1: Mockup UI in Figma, research Rust libraries to be used, init repo

Week 2: Rough UI skeleton, basic window/layout, placeholder views

Week 3: Implement ability to add/remove directories

Week 4: UI population

Week 5: Basic playback implementation

Week 6: Basic queue implementation

Week 7: Metadata scanning

Week 8: OS integration

Week 9: Polish settings panel

Week 10: Polish UI generally

Week 11 onward: Album art display, performance optimizations, UI prettification.

# Build instructions:
- Clone the repo with `git clone https://github.com/twigform/otic`
- cd into the repo (`cd otic`)
- simply run `cargo run`! that's it.
