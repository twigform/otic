# otic

**A local music player made in Slint and Rust**

</div>

> This is a project for school, but hopefully it'll also be an actually usable application by the end!

| Week | Goal |

| Week 8 | OS integration |
| Week 9 | Polish settings panel |

---

## Build instructions:
You'll need to have [Rust](https://www.rust-lang.org/tools/install) installed.

```sh
git clone https://github.com/twigform/otic
cd otic
cargo run
```
